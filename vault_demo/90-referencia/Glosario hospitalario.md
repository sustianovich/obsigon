# Glosario hospitalario

Siglas, términos y sinónimos de organización hospitalaria —áreas, gestión asistencial,
sistemas de información, pruebas diagnósticas, cribado y categorías profesionales— que
aparecen en las notas de este vault.

## Objetivo

Resolver las siglas y unificar la terminología usada en el resto de notas, para que una
consulta formulada con el sinónimo llegue igualmente a la nota correcta.

## Alcance

Recoge términos de organización y gestión hospitalaria. No incluye terminología clínica ni
codificación diagnóstica detallada.

## Desarrollo

### Áreas y unidades

| Término | Definición |
|---|---|
| SUH | Servicio de urgencias hospitalarias. Ver [[Urgencias]] |
| CCEE | Consultas externas. Ver [[Consultas externas]] |
| UCI / UMI | Unidad de cuidados intensivos o de medicina intensiva. Ver [[Cuidados intensivos]] |
| URPA | Unidad de recuperación postanestésica, el despertar tras la cirugía |
| CMA | Cirugía mayor ambulatoria: intervención sin pernocta |
| Planta | Nombre coloquial de [[Hospitalización|hospitalización]] |

### Gestión asistencial

| Término | Definición |
|---|---|
| Episodio | Contacto asistencial identificado: una urgencia, un ingreso, una consulta |
| Estancia media | Días de ingreso dividido entre número de altas |
| Índice de ocupación | Camas ocupadas sobre camas disponibles, en porcentaje |
| Triaje | Clasificación del paciente por gravedad al llegar a urgencias |
| CMBD | Conjunto mínimo básico de datos: registro codificado de cada alta |
| CIE-10 | Clasificación internacional de enfermedades usada para codificar |
| Lista de espera | Pacientes pendientes de consulta, prueba o intervención |

### Sistemas de información

| Término | Definición |
|---|---|
| HIS | Sistema de información hospitalaria, el núcleo administrativo-asistencial |
| HCE | Historia clínica electrónica |
| LIS | Sistema de información del laboratorio |
| RIS | Sistema de información de radiología |
| PACS | Archivo y distribución de imágenes médicas |
| HL7 / FHIR | Estándares de mensajería e interoperabilidad sanitaria |
| DICOM | Estándar de imagen médica |

### Pruebas y diagnóstico

| Término | Definición |
|---|---|
| TAT | Tiempo de respuesta de una prueba, desde la muestra al resultado |
| Valor crítico | Resultado que obliga a avisar de inmediato al clínico |
| Biopsia | Muestra de tejido para estudio en [[Anatomia patológica|anatomía patológica]] |
| TC / RM | Tomografía computarizada y resonancia magnética |

### Cribado y prevención

| Término | Definición |
|---|---|
| Cribado | Prueba aplicada a población sana para detectar enfermedad sin síntomas |
| Población diana | Grupo al que el programa dirige la invitación |
| Participación | Personas que se hacen la prueba sobre las invitadas |
| VPP | Valor predictivo positivo: enfermos reales entre los resultados positivos |
| Infección nosocomial | Infección adquirida durante la asistencia sanitaria |

### Categorías profesionales

| Término | Definición |
|---|---|
| TCAE | Técnico en cuidados auxiliares de enfermería |
| TSID | Técnico superior en imagen para el diagnóstico |
| Facultativo | Médico o farmacéutico del hospital |
| Instrumentista | Enfermera que asiste directamente en el campo quirúrgico |
